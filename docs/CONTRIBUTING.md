# Contributing

Thank you for your interest in contributing!

## How to Contribute

### Report Issues

- Check [existing issues](https://github.com/SwiftyJourney/requirements-engineering-skill/issues)
- Create new issue with clear description
- Include steps to reproduce (for bugs)

### Suggest Enhancements

We welcome:

- New BDD patterns
- Additional use case templates
- More diagram examples
- Documentation improvements

### Pull Requests

1. Fork the repository
2. Create feature branch: `git checkout -b feature/your-feature`
3. Make changes
4. Commit: `git commit -m "Add: new BDD pattern"`
5. Push: `git push origin feature/your-feature`
6. Open Pull Request

## Testing

Before submitting:

1. Test with an AI agent
2. Verify examples work
3. Check documentation is clear
